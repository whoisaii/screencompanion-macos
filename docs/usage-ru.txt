ScreenCompanion для macOS — 0.4.6-mac.1

ЗАПУСК
1. Открой ScreenCompanion.app. При желании сначала перетащи его в «Программы».
2. В настройках выбери AI-сервис, укажи API-ключ и нажми «Сохранить».
   Ключ вводится в самом приложении, присылать его в чат не нужно.
3. Дай приложению разрешение на запись экрана:
   Системные настройки → Конфиденциальность и безопасность → Запись экрана
   (на некоторых версиях: «Запись экрана и системного аудио»).
   Если после разрешения снимок не работает, полностью закрой и снова открой приложение.
4. Покажи вопрос на экране и нажми «Снимок и ответ».
   На нескольких мониторах захватывается тот, на котором находится указатель мыши.

Требования: Mac с Apple Silicon (M1/M2/M3/M4 и новее), macOS 14+.
Сборка и запуск проверены на этом Mac: arm64, macOS 26.1.
Windows, Wine, .NET, Python и Xcode для запуска не нужны.
Сборка подписана локальной подписью; нотариальной проверки Apple нет.
Если macOS блокирует полученную копию, после попытки запуска используй
«Всё равно открыть» в разделе «Конфиденциальность и безопасность».
Не отключай Gatekeeper целиком.

СОЧЕТАНИЯ ПО УМОЛЧАНИЮ
⌃⇧Space — снимок экрана и ответ (Control + Shift + пробел)
⌃/ — показать / скрыть панель
⌃⌥T — тест записи экрана
⌃⌥S — настройки
⌃⌥Q — завершить приложение
⌃⌫ — ввести вопрос

Все сочетания меняются в настройках. Требуется клавиша-модификатор.
Если окно скрыто, команды также доступны через значок в строке меню.
Перемещение — за шапку панели, изменение размера — за край окна.
Вопрос можно отправить со снимком или без него. Ответ можно выделить и скопировать.
Кнопка «Отмена» прекращает текущий запрос; уже обработанная сервисом часть
может учитываться в его оплате.

ВОЗМОЖНОСТИ
• Плавающая панель поверх обычных окон и на разных рабочих столах.
• Чтение экрана, автоматическое выделение области вопроса, ответ модели.
• Ввод вопроса с экранным контекстом или без него.
• Режимы: кратко, по шагам, перевод на английский, суммаризация, своя инструкция.
• OpenAI, Groq, Google Gemini, Mistral и OpenRouter.
• Раздельный выбор модели чтения экрана и модели ответа; отдельные ключи сервисов.
• Настройки цветов, размера текста, прозрачности фона и видимости текста.
• Изменяемые сочетания клавиш, сохранение настроек и размера панели.
• Локальный тест снимка, не отправляющий его AI-сервисам.

ЧТО ОТЛИЧАЕТСЯ ОТ WINDOWS
Это новая нативная реализация по функциям и данным из предоставленного EXE 0.4.6,
а не перепакованный EXE и не исходный проект автора. Точное совпадение интерфейса,
всех внутренних алгоритмов и поведения оригинала не подтверждено.

Скрытие от сторонней записи экрана НЕ гарантируется. Панель запрашивает системное
ограничение общего доступа, но современные программы захвата могут его игнорировать.
Проверяй результат записи/трансляции каждой программы отдельно.
Из собственных снимков ScreenCompanion исключает все окна своего процесса.

Оригинальные Windows-хранилища ключей не импортируются: ключ нужно ввести заново.
Вместо Windows-защиты используется Связка ключей macOS.
Горячие клавиши адаптированы для Mac; сочетания без модификаторов не поддерживаются.
В оригинале обнаружены дополнительные переменные окружения, режим QA и повторные
запросы при отказах. В этой версии их нет; отказ сервиса показывается пользователю.
Для чтения сначала выделяется одна общая область, затем транскрибируется её содержимое.
Модель ответа получает транскрипцию и изображение области; отдельные схемы вопросов,
вариантов и диаграмм оригинала не воспроизводятся побайтово.

AI-СЕРВИСЫ И ПРИВАТНОСТЬ
Модели по умолчанию взяты из предоставленного EXE. Их доступность не гарантирована.
Можно вписать другой точный ID модели. Обе модели должны поддерживать изображения;
для автоматической обрезки модель чтения должна поддерживать строгий JSON Schema.

API-ключ хранится в Связке ключей. Подписка на чат сама по себе не заменяет API-доступ.
Снимки/вопросы отправляются выбранному сервису только по команде пользователя.
При автоматической обрезке полный экран сначала отправляется модели чтения;
обрезка не защищает остальную часть экрана от этого первого запроса.
За один ответ выполняется 3 запроса с обрезкой или 2 без неё; без снимка — 1.
Оплата, лимиты, обучение и хранение данных зависят от сервиса и аккаунта.
Для OpenAI используется store=false; это не универсальная гарантия нулевого хранения.

Снимки и вопросы не пишутся приложением на диск. Текущий ответ находится в памяти;
при копировании он попадает в системный буфер обмена.
Настройки: ~/Library/Application Support/ScreenCompanionMac/settings.json
Журнал ошибок: в той же папке diagnostics.log. Журнал содержит время, тип и код ошибки,
но не ключи, вопросы, снимки или тела ответов.

ПРОВЕРКИ
Успешно собрана нативная arm64-сборка; приложение открыто на этом Mac.
Проверены сериализация настроек, формирование запросов для пяти сервисов,
разбор успешных/пустых/отклонённых/незавершённых ответов, геометрия области и JPEG.
Проверены интерфейс настроек и наличие панели при запуске.
Настоящие AI-запросы не проверены: API-ключ не предоставлен.
Снимок с разрешением macOS, сторонние записи экрана, каждый сервис и все сочетания
нужно проверить в пользовательском окружении; полного теста совместимости не было.
